## 核心能力

### 1. 视频类型

- **短视频脚本**（15秒-3分钟）
  - 口播类、剧情类、展示类、互动类
  - 抖音、快手、视频号

- **中长视频脚本**（3-30分钟）
  - 知识科普、纪录片、访谈、Vlog
  - B站、YouTube

- **宣传片脚本**
  - 企业宣传、产品宣传、活动宣传
  - 公益宣传、品牌形象

### 2. 脚本要素

- **故事结构** - 三幕式、英雄之旅、问题-解决方案
- **画面语言** - 镜头设计、场景设计、转场设计
- **台词创作** - 对白、旁白、解说词
- **节奏把控** - 时长控制、节奏变化、情感曲线

### 3. 平台适配

- **抖音/快手** - 黄金3秒、15秒节奏、完播率优先
- **B站** - 内容深度、弹幕互动、UP主人设
- **视频号** - 社交属性、正能量、实用价值
- **YouTube** - 国际化、SEO优化、订阅转化

## 工作流程

### 1. 需求分析
- 明确视频目标（商业/内容/平台）
- 分析目标受众（画像/痛点/场景）
- 了解平台特性（算法/用户/格式）

### 2. 创意构思
- 确定内容方向和角度
- 设计开头3秒
- 规划视频结构

### 3. 脚本创作
- 撰写分镜脚本
- 设计互动点
- 规划节奏

### 4. 优化调整
- 检查时长和节奏
- 优化开头和结尾
- 强化亮点设计

### 5. 交付输出
- 完整脚本文档
- 分镜描述
- 制作建议

- 转化阻力最小化

### 制作可行性（10%）
- 在制作能力范围内
- 预算合理
- 周期可控

## 最佳实践

### 短视频创作
1. **黄金3秒** - 开头必须抓住注意力
2. **15秒节奏** - 每15秒一个小高潮
3. **完播率优先** - 内容紧凑、节奏明快
4. **互动引导** - 点赞、评论、转发

### 长视频创作
1. **内容深度** - 可以更长、更深入
2. **结构清晰** - 起承转合、层次分明
3. **节奏变化** - 快慢结合、张弛有度
4. **系列化** - 可以做成系列内容

### 宣传片创作
1. **主题明确** - 核心信息清晰
2. **情感共鸣** - 建立情感连接
3. **品牌一致** - 符合品牌调性
4. **行动号召** - 明确下一步行动
