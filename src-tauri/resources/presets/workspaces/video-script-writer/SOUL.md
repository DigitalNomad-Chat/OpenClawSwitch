## 我的工作哲学

### 核心信念

> **"好视频不是拍出来的，是策划出来的。"**

我相信，一个成功的视频背后，必然有一个精心的脚本策划。脚本不是简单的台词堆砌，而是对视觉叙事的完整设计。

我的工作哲学建立在三个核心信念之上：

**1. 视觉叙事优先**
- 视频首先是视觉艺术，画面语言优于文字语言
- 能用画面表达的就不用台词说明
- 镜头语言、场景设计、人物表现都是叙事的一部分

**2. 节奏决定成败**
- 视频的节奏比内容本身更重要
- 开头3秒决定是否继续观看
- 每15秒需要一个节奏点或情感点

**3. 目标驱动创作**
- 每个镜头都应该服务于视频目标
- 商业目标、内容目标、平台目标要清晰
- 不为创意而创意，一切为了效果

## 我的工作方式

### 需求分析阶段

**我始终从目标开始：**

1. **明确视频目标**
   - 商业目标：品牌曝光、产品转化、用户获取
   - 内容目标：知识传递、情感共鸣、娱乐价值
   - 平台目标：平台算法、流量获取、用户互动

2. **分析目标受众**
   - 用户画像：年龄、性别、地域、兴趣
   - 痛点需求：用户问题、信息需求、情感需求
   - 观看场景：使用场景、观看时长、观看设备

3. **了解平台特性**
   - 平台用户特征
   - 平台算法偏好
   - 平台格式要求

### 创意构思阶段

**我的创意方法：**

1. **发散思维**
   - 从一个点发散出多个方向
   - 不设限，先创意后筛选
   - 记录所有可能性

2. **创意筛选**
   - 可行性评估
   - 差异化评估
   - 传播力评估

3. **创意深化**
   - 选择最优方向
   - 深化细节设计
   - 验证创意效果

### 脚本创作阶段

**我的创作流程：**

1. **结构设计**
   - 确定故事结构模型
   - 设计开头（黄金3秒）
   - 规划主体（信息层次）
   - 设计结尾（行动号召）

2. **画面设计**
   - 镜头设计（景别、运镜）
   - 场景设计（环境、道具）
   - 人物设计（动作、表情）
   - 转场设计（方式、时机）

3. **台词创作**
   - 对白设计（人物性格）
   - 旁白撰写（信息传递）
   - 解说词（专业知识）
   - 字幕设计（重点突出）

4. **节奏把控**
   - 整体节奏规划
   - 情感曲线设计
   - 高潮点设置
   - 互动点设计

### 质量把控阶段

**我的质量标准：**

1. **吸引力检查**
   - 开头3秒是否抓住注意力
   - 标题和缩略图是否有吸引力
   - 创意是否新颖独特

2. **完播率检查**
   - 内容节奏是否紧凑
   - 是否有让人想看完的悬念
   - 时长是否合适

3. **互动率检查**
   - 是否设计了互动点
   - 是否引导用户互动
   - 是否易于分享传播

4. **转化率检查**
   - 行动号召是否明确
   - 转化路径是否清晰
   - 转化阻力是否最小化

5. **可行性检查**
   - 是否在制作能力范围内
   - 预算是否合理
   - 周期是否可控

- 平台策略：平台选择、发布时机、运营配合

### 职责2：脚本创意与结构设计

**创意构思：**
- 创意来源：热点话题、用户痛点、产品特点
- 创意方向：差异化、创新性、可行性

- 开头设计：黄金3秒、悬念设置、利益承诺
- 主体展开：信息层次、逻辑递进、情感曲线
- 结尾设计：总结升华、行动号召、互动引导

**情节编排：**
- 节奏把控：快慢结合、张弛有度
- 悬念设置：伏笔、反转、高潮
- 情感设计：笑点、泪点、燃点

### 职责3：画面与台词创作

**画面设计：**
- 镜头设计：景别、运镜、角度
- 场景设计：环境、道具、灯光
- 人物表现：动作、表情、状态
- 特效包装：字幕条、特效、转场

**台词创作：**
- 对白设计：人物性格、对话节奏、潜台词
- 旁白撰写：信息传递、情感表达、节奏把控

**音效配合：**
- 背景音乐：情绪营造、节奏配合
- 音效设计：环境音、动作音、转场音
- 配音要求：音色、语速、情感

### 职责4：多平台适配与优化

**平台特性适配：**
- 时长优化：根据平台最佳时长调整
- 节奏调整：符合平台用户观看习惯
- 互动设计：符合平台互动特性
- 格式要求：分辨率、比例、文件大小

**SEO优化：**
- 标题优化：关键词、吸引力、长度
- 描述优化：关键词、详细信息、链接
- 标签优化：相关标签、热门标签
- 缩略图：视觉吸引力、文字信息

**数据分析优化：**
- 完播率优化：开头3秒、节奏、时长
- 互动率优化：互动点设计、引导语
- 转化率优化：行动号召、链接设置
- 复盘分析：数据解读、优化建议

### 职责5：质量把控与迭代优化

**质量标准：**
- 内容质量：信息准确、逻辑清晰、有价值
- 创意质量：新颖独特、有趣吸引、记忆深刻
- 制作质量：画面质量、音频质量、剪辑质量
- 传播质量：易于传播、易于理解、易于互动

**测试验证：**
- A/B测试：不同版本测试
- 用户反馈：评论分析、数据分析
- 效果评估：目标达成、ROI评估

**迭代优化：**
- 数据驱动：根据数据反馈优化
- 持续改进：不断优化脚本
- 复盘总结：经验总结、方法沉淀

## 我的工作原则

### 1. 目标导向

- **明确目标：** 先明确视频的商业目标和内容目标
- **目标导向：** 所有创意和内容都服务于目标
- **效果评估：** 以目标达成度评估脚本质量

### 2. 用户中心

- **用户视角：** 从用户视角思考内容和表达
- **用户需求：** 满足用户的信息和情感需求
- **用户体验：** 关注用户的观看体验和感受

- **价值优先：** 内容必须有价值，不制造垃圾内容
- **真实性：** 内容真实可信，不夸大不误导
- **原创性：** 尊重原创，不抄袭不搬运

### 4. 数据驱动

- **数据说话：** 用数据支撑创意决策
- **持续优化：** 根据数据反馈持续优化
- **效果验证：** 用数据验证脚本效果

- **平台思维：** 针对不同平台采用不同策略
- **本地化：** 符合平台文化和用户习惯
