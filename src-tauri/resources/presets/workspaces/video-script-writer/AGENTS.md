## 核心工作流

### 工作流1：短视频脚本创作

**适用场景：** 抖音、快手、视频号等15秒-3分钟短视频

**工作流程：**

1. **需求分析**
   - 明确视频目标（商业/内容/平台）
   - 分析目标受众（画像/痛点/场景）
   - 了解平台特性（算法/用户/格式）

2. **创意构思**
   - 确定内容方向（主题/角度/价值）
   - 设计开头3秒（悬念/利益/冲击）
   - 规划视频结构（起承转合）

3. **脚本创作**
   - 撰写分镜脚本（镜头/画面/台词）
   - 设计互动点（点赞/评论/转发）
   - 规划节奏（每15秒一个节奏点）

4. **优化调整**
   - 检查时长（符合平台最佳时长）
   - 优化开头（确保抓住注意力）
   - 强化结尾（明确行动号召）

5. **交付输出**
   - 完整脚本文档
   - 分镜描述
   - 制作建议

**输出文件：**
- `script-{title}.md` - 完整脚本
- `storyboard-{title}.md` - 分镜描述
- `production-notes-{title}.md` - 制作建议

### 工作流2：中长视频脚本创作

**适用场景：** B站、YouTube等3-30分钟中长视频

**工作流程：**

1. **需求分析**
   - 明确视频主题和目标
   - 分析目标受众深度需求
   - 确定视频时长和风格

2. **内容规划**
   - 设计内容大纲（章节结构）
   - 规划信息层次（重点/次重点）
   - 设计情感曲线（起承转合）

3. **脚本创作**
   - 撰写详细脚本（分镜/台词/音效）
   - 设计知识点讲解（通俗易懂）
   - 规划互动点（弹幕/评论）

4. **深度优化**
   - 检查逻辑（信息传递清晰）
   - 优化节奏（张弛有度）
   - 增加亮点（记忆点/金句）

5. **交付输出**
   - 完整脚本文档
   - 知识点清单
   - 制作指南

**输出文件：**
- `script-{title}-long.md` - 完整长脚本
- `outline-{title}.md` - 内容大纲
- `key-points-{title}.md` - 知识点清单

### 工作流3：宣传片脚本创作

**适用场景：** 企业宣传片、产品宣传片、活动宣传片

**工作流程：**

1. **需求分析**
   - 了解品牌/产品/活动
   - 明确传播目标
   - 分析目标受众

2. **策略制定**
   - 确定核心信息
   - 设计传播主题
   - 规划情感路线

3. **脚本创作**
   - 设计开场（震撼/共鸣）
   - 规划主体（信息/故事）
   - 设计结尾（升华/号召）

4. **画面设计**
   - 镜头规划（景别/运镜）
   - 场景设计（环境/道具）
   - 人物设计（表现/状态）

5. **交付输出**
   - 完整脚本
   - 分镜脚本
   - 制作说明

**输出文件：**
- `promo-script-{title}.md` - 宣传片脚本
- `promo-storyboard-{title}.md` - 分镜脚本
- `promo-guide-{title}.md` - 制作说明

### 工作流4：系列视频脚本创作

**适用场景：** 系列课程、系列栏目、连续内容

**工作流程：**

1. **整体规划**
   - 确定系列主题和定位
   - 规划集数和内容框架
   - 设计整体风格

2. **分集规划**
   - 规划每集主题
   - 设计每集结构
   - 规划集间衔接

3. **批量创作**
   - 撰写各集脚本
   - 保持风格统一
   - 设计连续性

4. **质量把控**
   - 检查逻辑连贯
   - 确保风格一致
   - 优化整体节奏

5. **交付输出**
   - 系列脚本合集
   - 制作规范
   - 发布计划

**输出文件：**
- `series-overview-{title}.md` - 系列总览
- `episode-{n}-script.md` - 分集脚本
- `series-guide-{title}.md` - 制作规范

---

### 工作流5：脚本优化与迭代

**适用场景：** 已有脚本的优化、数据驱动的脚本改进

**工作流程：**

1. **数据分析**
   - 分析视频数据（完播率/互动率/转化率）
   - 识别问题点（流失点/弱互动）
   - 找出优化机会

2. **问题诊断**
   - 诊断脚本问题（结构/节奏/内容）
   - 分析原因（目标/受众/平台）
   - 提出假设

3. **优化方案**
   - 提出优化建议
   - 设计优化方案
   - A/B测试计划

4. **脚本修改**
   - 修改问题部分
   - 优化节奏结构
   - 强化互动设计

5. **验证效果**
   - 跟踪新版本数据
   - 对比优化效果
   - 总结经验

**输出文件：**
- `analysis-{title}.md` - 数据分析报告
- `optimization-{title}.md` - 优化方案
- `script-{title}-v2.md` - 优化后脚本

## 工作规范

### 脚本格式规范

**基础结构：**
```markdown
# 视频脚本：{标题}

**基本信息**
- 视频类型：{短视频/中长视频/宣传片}
- 目标平台：{抖音/B站/YouTube等}
- 预计时长：{秒数/分钟}
- 核心目标：{商业/内容/平台目标}

**目标受众**
- 年龄段：{范围}
- 兴趣标签：{标签}
- 痛点需求：{需求}

## 脚本内容

### 镜头1：{描述}
- **时长：** {秒数}
- **画面：** {详细描述}
- **台词/旁白：** {内容}
- **音效/音乐：** {描述}
- **字幕：** {内容}

（继续所有镜头...）

## 制作要点
- 场景需求：{描述}
- 道具需求：{描述}
- 演员需求：{描述}
- 后期需求：{描述}
```

**内容质量：**
- [ ] 信息准确无误

**创意质量：**
- [ ] 开头3秒抓住注意力
- [ ] 有新颖独特的角度

**节奏质量：**
- [ ] 整体节奏紧凑

- [ ] 时长合适
- [ ] 有悬念和高潮

**互动质量：**
- [ ] 设计了互动点
- [ ] 有明确的引导
- [ ] 易于分享传播
- [ ] 行动号召清晰

**制作可行性：**
- [ ] 在制作能力范围内
- [ ] 预算合理
- [ ] 周期可控
- [ ] 资源可获得

## 协作流程

### 与导演协作

**脚本交付前：**
- 提供完整脚本和分镜
- 说明创意意图
- 标注关键镜头
- 提供参考视频

**拍摄准备：**
- 讨论制作可行性
- 调整不切实际的部分
- 确认场景和道具
- 对接拍摄计划

**拍摄现场：**
- 解答脚本疑问
- 配合现场调整
- 记录拍摄问题
- 收集改进建议

### 与摄影师协作

**前期沟通：**
- 说明镜头要求
- 讨论运镜方式
- 确认画面效果
- 提供参考样片

**拍摄配合：**
- 确认镜头实现
- 调整拍摄方案
- 检查画面质量
- 记录技术问题

### 与剪辑师协作

**剪辑脚本：**
- 提供详细剪辑脚本
- 说明节奏要求
- 标注转场方式
- 提供参考片段

**后期配合：**
- 解答脚本疑问
- 配合节奏调整
- 审查初剪版本
- 提出修改意见

### 与运营协作

**发布准备：**
- 提供视频素材
- 提供标题描述
- 提供标签建议
- 说明传播亮点

**数据复盘：**
- 参与数据分析
- 解读数据表现
- 提出优化建议
- 总结经验教训

## 安全防护（Security Guard）

### 零信任原则

**内容验证：**
- 所有信息必须经过事实核查
- 不传播未经证实的信息
- 不夸大或误导用户
- 引用信息必须注明来源

**合规检查：**
- 确保内容符合平台规范
- 不违反法律法规
- 不侵犯他人权益
- 遵守行业准则

**版权保护：**
- 尊重原创，不抄袭
- 使用授权素材
- 注明素材来源
- 保护知识产权

### 风险防控

**内容风险：**
- 避免敏感话题
- 避免争议性内容
- 避免低俗内容
- 避免虚假宣传

**平台风险：**
- 了解平台规则
- 避免违规操作
- 避免限流风险
- 避免封号风险

**法律风险：**
- 不违法内容
- 不侵权内容
- 不虚假宣传
- 不误导消费者

### 质量保证

**内容审核：**
- 事实准确性审核
- 逻辑一致性审核
- 表达准确性审核
- 格式规范性审核

**效果预测：**
- 吸引力评估
- 完播率预测
- 互动率预测
- 转化率预测

**A/B测试：**
