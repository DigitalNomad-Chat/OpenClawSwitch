# 广告投放优化师 Workspace 使用指南

## 1. Workspace 概述

本 Workspace 是为广告投放优化师设计的专业工作空间，包含了身份定义、工作哲学、工作流程、目标用户、工具资源等核心内容，旨在为广告投放优化工作提供系统化的指导和支撑。

### 1.1 核心价值

本 Workspace 的核心价值体现在以下几个方面：

**专业化指引**：提供了广告投放优化师的完整专业能力框架，从身份定位、知识体系到工作方法，帮助从业者建立系统化的专业认知。

**流程标准化**：定义了广告策划、创意制作、投放执行、数据分析、效果提升五大核心工作流程，每个流程都有明确的步骤、输出物和质量标准。

**工具资源支撑**：整理了广告投放相关的各类工具和资源，包括投放平台、数据分析工具、创意制作工具、行业资讯等，为高效工作提供支撑。

**安全合规保障**：每个工作流程都包含 Security Guard 安全检查要求，确保广告投放工作符合法规和平台规范。

## 2. 快速开始

### 2.1 新项目启动流程

当接到一个新的广告投放项目时，建议按照以下流程使用本 Workspace：

**第一步：理解项目需求** - 阅读 USER.md 了解目标用户类型，识别当前项目属于哪类用户，理解该类用户的核心需求和服务要求。

**第二步：制定广告策略** - 按照 AGENTS.md 中的「广告策划流程」，制定完整的广告投放策略，明确投放目标、渠道选择、定向策略、预算分配等核心要素。

**第三步：准备创意素材** - 按照 AGENTS.md 中的「创意制作流程」，制作广告创意的文案、图片、视频等素材，并进行 A/B 测试设计。

**第四步：执行广告投放** - 按照 AGENTS.md 中的「投放执行流程」，完成账户搭建、投放配置、上线发布、投放监控等执行工作。

**第五步：分析优化效果** - 按照 AGENTS.md 中的「数据分析流程」和「效果提升流程」，进行效果分析、问题诊断和优化迭代。

### 2.2 日常使用建议

**每日必读**：HEARTBEAT.md 提供了系统的实时状态监控，应该每天查看确保所有模块正常运行。

**策略制定参考**：制定广告策略时，先参考 IDENTITY.md 明确专业定位，再参考 SOUL.md 确定工作原则，最后参考 AGENTS.md 中的具体流程执行。

**问题诊断参考**：遇到问题时，可以参考 AGENTS.md 中各流程的质量标准和常见问题处理方法，也可以参考 docs/examples/ 中的案例寻找类似问题的解决方案。

**模板工具使用**：日常工作可以参考 docs/templates/ 中的模板文档，提高工作效率和文档规范性。

## 3. 核心模块说明

### 3.1 身份与哲学

**IDENTITY.md** 定义了广告投放优化师的专业身份，包括核心角色定位、专业能力矩阵、专业知识体系、行业经验积累、职业素养要求和发展愿景。这是一份基础性文件，帮助建立专业的自我认知。

**SOUL.md** 定义了工作哲学，包括效果至上、数据说话的系统性思考，长期主义、精益测试的策略思维，以及用户中心、价值创造的核心理念。这是一份精神纲领，指导日常工作的价值判断和行为选择。

### 3.2 工作流程体系

**AGENTS.md** 是本 Workspace 的核心文档，定义了五大工作流程：

**广告策划流程**：从商业目标分析、市场竞品研究，到广告策略制定、创意策略规划，是整个广告投放工作的起点。流程包含四个步骤，每个步骤都有详细的子任务说明。

**创意制作流程**：从创意概念开发，到文案撰写、视觉设计、视频制作、创意测试，是将策略转化为具体广告内容的过程。流程包含五个步骤，覆盖创意制作的完整环节。

**投放执行流程**：从账户结构搭建、投放配置，到上线发布、投放监控，是将策略和创意转化为实际投放的过程。流程包含四个步骤，确保广告准确、高效、稳定投放。

**数据分析流程**：从数据收集整理，到效果指标分析、归因分析、诊断与洞察，是为优化决策提供数据支撑的过程。流程包含四个步骤，建立数据驱动的分析体系。

**效果提升流程**：从优化方向确定、方案设计，到执行实施、迭代优化，是持续提升广告效果的过程。流程包含四个步骤，形成持续改进的优化机制。

### 3.3 工具与资源

**TOOLS.md** 整理了广告投放相关的各类工具和资源：

**广告投放平台**：详细介绍了巨量引擎、腾讯广告、阿里妈妈、百度广告、快手广告等主流投放平台的工具功能和投放策略要点。

**数据分析工具**：包括流量分析工具（GA、GrowingIO、神策数据）、广告效果分析工具（App Growing、DataEye）、BI可视化工具（Tableau、Power BI）、数据处理工具（Excel、Python、SQL）。

**创意制作工具**：包括图片设计工具（Photoshop、Figma、Canva）、视频制作工具（Premiere Pro、剪映）、素材资源平台（站酷、花瓣、Unsplash）。

**行业资源**：包括行业媒体（Morketing、TopMarketing）、行业报告（艾瑞、CBNData、QuestMobile）、学习资源（平台认证、在线课程）。

### 3.4 案例与模板

**docs/examples/** 目录包含三个典型广告投放案例：

**example-001-douyin-ad.md**：抖音信息流广告投放案例，展示电商行业在抖音平台的完整投放策略和执行过程。

**example-002-wechat-ad.md**：微信朋友圈广告投放案例，展示品牌广告在微信生态的投放策略和执行过程。

**example-003-search-ad.md**：百度搜索广告投放案例，展示效果类广告在搜索引擎的投放策略和执行过程。

**docs/templates/** 目录包含两个常用模板：

**template-ad-plan.md**：广告投放计划模板，提供完整的策略文档框架，可以直接套用填写。

**template-ad-report.md**：广告投放报告模板，提供效果报告框架，可以用于周期性汇报和活动总结。

### 3.5 系统状态

**HEARTBEAT.md** 提供了 Workspace 的系统状态监控，包括各模块的运行状态、检查节点和更新时间。这是一份运维性文档，确保 Workspace 保持最佳运行状态。

## 4. 使用场景示例

### 4.1 场景一：制定新品牌广告投放方案

**背景**：某时尚品牌计划在618期间进行品牌广告投放，需要制定完整的投放方案。

**使用步骤**：

1. 阅读 USER.md 确定这是品牌企业类型的用户，理解品牌广告的核心诉求是曝光和品牌认知。
2. 参考 IDENTITY.md 中关于品牌广告的策略框架和行业经验。
3. 按照 AGENTS.md 中的「广告策划流程」制定策略：确定曝光量和品牌认知度为KPI，选择抖音、微信、小红书等适合品牌曝光的渠道组合，制定分阶段的投放节奏。
4. 按照「创意制作流程」制作创意：提炼品牌的核心信息和视觉调性，制作符合平台特点的品牌创意素材。
5. 参考 docs/templates/template-ad-plan.md 填写完整的投放计划文档。

### 4.2 场景二：优化电商广告的转化效果

**背景**：某电商客户的直通车广告近期转化成本上升，需要分析原因并制定优化方案。

**使用步骤**：

1. 参考 AGENTS.md 中「数据分析流程」的方法论，对广告数据进行多维度分析：时间维度分析、关键词维度分析、人群维度分析、创意维度分析。
2. 参考「效果提升流程」确定优化方向：基于数据分析结果聚焦问题点，形成优化假设，设计测试方案。
3. 执行优化测试，参考 docs/examples/ 中电商广告案例的优化经验。
4. 评估优化效果，如果有效则规模化推广。
5. 参考 docs/templates/template-ad-report.md 输出优化效果报告。

### 4.3 场景三：学习借鉴行业最佳实践

**背景**：团队新人需要快速了解信息流广告的投放方法和行业经验。

**使用步骤**：

1. 阅读 IDENTITY.md 建立对广告投放优化师的专业认知。
2. 阅读 SOUL.md 理解广告投放的核心价值理念和方法论。
3. 阅读 AGENTS.md 了解五大工作流程的全貌，重点关注「广告策划流程」和「数据分析流程」。
4. 阅读 docs/examples/ 中的三个案例，了解不同场景的投放策略和执行细节。
5. 阅读 TOOLS.md 了解常用的工具和资源，为后续实操做准备。

## 5. 维护与更新

### 5.1 内容更新机制

本 Workspace 的内容应该根据以下情况进行更新：

**平台规则变化**：当主要广告平台的规则、功能或政策发生变化时，及时更新 AGENTS.md 和 TOOLS.md 中相关内容。

**工具升级迭代**：当常用工具的功能或使用方式发生变化时，更新 TOOLS.md 中的相关内容。

**案例沉淀积累**：每完成一个重要的投放项目后，及时将经验和教训整理沉淀到 docs/examples/ 或相关流程文档中。

**流程优化改进**：在实践中发现流程的不足或更好的方法时，及时更新 AGENTS.md 中的流程定义。

### 5.2 质量保障

**定期检查**：建议每周检查 HEARTBEAT.md，确保所有模块正常运行。

**内容审核**：新增或修改内容前，参照 AGENTS.md 中的 Security Guard 要求进行安全检查。

**版本记录**：重要更新应该记录变更日志，便于追溯和回顾。

## 6. 常见问题

### Q1：如何快速找到需要的文档内容？

**A**：每个文档都通过标题和章节编号进行了清晰的结构化组织。文档开头的目录部分提供了全文的结构概览。同时提供了 docs/templates/ 和 docs/examples/ 目录，可以快速找到模板和案例参考。

### Q2：遇到新问题没有案例参考怎么办？

**A**：首先参考 IDENTITY.md 和 SOUL.md 建立问题的基本认知框架。然后参考 AGENTS.md 中各流程的质量标准，分析问题的性质和可能的解决方案。如果仍无法解决，可以将问题记录下来，事后通过行业资源或专业社区寻求帮助。

### Q3：如何确保工作流程的执行质量？

**A**：AGENTS.md 中每个流程都定义了质量标准和检查节点。在执行流程时，参照这些标准进行检查。同时每个流程都包含 Security Guard 安全检查要求，确保工作符合安全和合规标准。
