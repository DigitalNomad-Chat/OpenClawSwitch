# 公关稿件撰写专家工具资源

## 一、工具体系总览

### 1.1 工具分类框架

本专家系统提供完整的公关稿件撰写工具体系，分为五大类别：

| 类别 | 功能 | 使用阶段 |
|-----|------|---------|
| 创作工具 | 内容生成、写作辅助 | 核心创作阶段 |
| 审核工具 | 合规检查、质量评估 | 内容审核阶段 |
| 优化工具 | 改写建议、版本管理 | 内容优化阶段 |
| 发布工具 | 格式转换、渠道适配 | 发布准备阶段 |
| 知识工具 | 素材库、案例库 | 全流程支持 |

### 1.2 工具使用原则

**效率优先**：选择最合适的工具完成特定任务，避免过度依赖工具而影响效率。

**质量为本**：工具服务于内容质量，工具的使用不能替代专业判断和内容打磨。

**安全合规**：使用的所有工具必须符合信息安全要求，不泄露敏感信息。

**持续更新**：根据实践反馈持续优化工具能力，保持工具的先进性和有效性。

## 二、创作工具集

### 2.1 内容生成工具

#### 2.1.1 新闻标题生成器

**功能说明**：
根据提供的新闻素材，自动生成多个候选标题供选择。

**使用方法**：
```
输入：
- 核心事件：[填写核心事件描述]
- 关键数据：[如有重要数据，填写数据]
- 目标媒体：[选择目标媒体类型]

输出：
- 标准新闻标题（3-5个）
- 社交媒体标题（3-5个）
- 备选标题（2-3个）
```

**标题类型支持**：

| 类型 | 特点 | 适用场景 |
|-----|------|---------|
| 客观陈述型 | 准确传达信息 | 严肃媒体、官方渠道 |
| 亮点突出型 | 强调核心亮点 | 商业媒体、新闻网站 |
| 悬念设置型 | 引发阅读兴趣 | 社交媒体、自媒体 |
| 数字驱动型 | 用数据吸引关注 | 财经媒体、科技媒体 |

#### 2.1.2 导语生成器

**功能说明**：
根据新闻核心信息，自动生成符合新闻写作规范的导语。

**导语类型**：

| 类型 | 结构 | 适用场景 |
|-----|------|---------|
| 直接导语 | 直接陈述最重要的事实 | 大多数新闻通稿 |
| 延缓导语 | 先描述场景或背景 | 特写、深度报道 |
| 引语导语 | 以引用语开头 | 人物专访、声明发布 |
| 对比导语 | 通过对比引出新闻 | 数据发布、排名报道 |
| 提问导语 | 以问题开头 | 调查报道、分析文章 |

#### 2.1.3 引用语生成器

**功能说明**：
根据发言人的身份和发言主题，生成专业、自然的引用语。

**引用语模板**：

```
结构模板：
[发言人身份]：[直接引用内容]。[补充说明或展望]。

示例：
XX公司首席执行官张明表示："[核心观点]",
他进一步指出："[补充内容或未来展望]"
```

**引用语优化建议**：
- 长度控制在30-60字之间
- 使用第一人称，表达个人态度
- 避免过于官方或空洞的表述
- 适当加入具体数据或案例支撑

## 三、审核工具集

### 3.1 准确性审核

#### 3.1.1 事实核查清单

**数据核实项**：
```
□ 数字准确性：金额、百分比、人数、时间等
□ 数据来源：是否有可靠来源支撑
□ 数据时效：是否使用最新数据
□ 数据单位：单位是否正确统一
□ 数据比较：比较对象是否恰当
□ 数据趋势：趋势描述是否准确
```

**事实核实项**：
```
□ 事件时间线是否准确
□ 地点信息是否正确
□ 人物身份和职务是否准确
□ 引用语是否与原话一致
□ 背景信息是否经过核实
□ 专业术语使用是否准确
```

#### 3.1.2 逻辑一致性检查

**逻辑检查要点**：
```
□ 标题与正文是否一致
□ 导语与主体是否对应
□ 各段落之间是否逻辑连贯
□ 结论是否与论据一致
□ 承诺是否与事实对应
□ 前后表述是否矛盾
```

### 3.2 得体性审核

#### 3.2.1 语气评估矩阵

| 稿件类型 | 建议语气 | 避免语气 |
|---------|---------|---------|
| 危机声明 | 诚恳、严肃、负责 | 推诿、轻描淡写 |
| 新闻通稿 | 客观、中立、专业 | 夸大、自吹 |
| 高管致辞 | 自信、亲和、有感染力 | 空洞说教 |
| 企业声明 | 正式、权威、清晰 | 模糊、含糊 |
| 庆功稿 | 热情、感恩、积极 | 过度炫耀 |

#### 3.2.2 分寸评估检查

```
得体性检查维度：

1. 态度恰当性
   □ 是否过于强硬或软弱
   □ 道歉是否真诚不过分
   □ 表态是否坚定不过激

2. 措辞分寸
   □ 是否使用绝对化表述
   □ 是否避免攻击性语言
   □ 承诺是否留有余地

3. 情感分寸
   □ 是否过度煽情
   □ 同理心表达是否恰当
   □ 情感与理性是否平衡
```

### 3.3 合规性审核

#### 3.3.1 法律风险检查

**自认风险**：
```
检查项：
□ 是否承认了可能加重责任的事实
□ 承诺内容是否能实际履行
□ 是否在调查结论前做出定性判断
□ 表述是否存在被扩大解读的风险

风险等级：
- 高风险：涉及法律责任的明确表态
- 中风险：可能引发质疑的解释说明
- 低风险：一般性事实陈述
```

**合规要点**：
```
□ 广告法合规：避免绝对化用语
□ 反不正当竞争法：避免贬低竞争对手
□ 个人信息保护：避免泄露个人信息
□ 知识产权：避免侵犯他人权利
□ 证券法规：涉及上市公司的信息披露要求
```

#### 3.3.2 监管合规检查

**行业特殊要求**：

| 行业 | 特殊合规要求 |
|-----|-------------|
| 金融 | 银保监/证监披露要求，风险提示 |
| 医疗健康 | 疗效表述限制，广告审查 |
| 食品 | 功效声称限制，安全提示 |
| 房地产 | 宣传规范，价格公示 |
| 教育 | 培训效果声明限制，资质公示 |

### 3.4 质量评分工具

**五维质量评估体系**：

| 维度 | 权重 | 评分要点 |
|-----|------|---------|
| 准确性 | 25% | 事实、数据、引用准确无误 |
| 得体性 | 25% | 语气、分寸、措辞恰当 |
| 时效性 | 20% | 及时响应，符合传播节奏 |
| 传播性 | 15% | 标题吸引，结构清晰，可读性强 |
| 合规性 | 15% | 法律合规，监管合规 |

**评分标准**：
```
优秀（90-100分）：全面达标，有亮点
良好（75-89分）：基本达标，少量优化空间
合格（60-74分）：核心达标，需要改进
不合格（60分以下）：存在明显问题，需要重写
```

## 四、优化工具集

### 4.1 改写建议工具

#### 4.1.1 标题优化建议

**标题问题诊断**：

| 问题类型 | 问题描述 | 优化建议 |
|---------|---------|---------|
| 信息缺失 | 缺少关键信息 | 补充核心要素 |
| 表述模糊 | 不够具体明确 | 具体化呈现 |
| 缺乏亮点 | 平淡无吸引力 | 加入亮点或悬念 |
| 过于冗长 | 字数超标 | 删除冗余，保留核心 |
| 违规风险 | 可能有合规问题 | 调整措辞 |

**标题优化示例**：

```
原标题：XX公司推出新产品
优化建议：
- 加入数据：XX公司推出新一代产品，性能提升40%
- 制造悬念：XX公司神秘新品曝光，有何不同？
- 具体化：XX公司发布首款折叠屏手机，售价9999元起
```

#### 4.1.2 正文优化建议

**段落优化诊断**：

| 问题 | 诊断标准 | 优化方向 |
|-----|---------|---------|
| 开头平淡 | 首段无法吸引阅读 | 重写开头，优先呈现核心 |
| 信息堆砌 | 段落过长，信息过载 | 分段处理，增加层次 |
| 逻辑混乱 | 论述缺乏条理 | 重组结构，增加过渡 |
| 重点不突出 | 核心信息不醒目 | 使用小标题，加粗强调 |
| 结尾乏力 | 收尾仓促或空洞 | 补充总结，增加号召 |

```
2. 行业适配度：模板是否考虑行业特点
3. 可定制性：模板是否便于修改调整
4. 时效性：模板是否反映最新实践
```

## 七、安全防护工具

### 7.1 信息安全检查

#### 7.1.1 敏感信息识别

**敏感信息类型**：

| 类型 | 识别特征 | 处理要求 |
|-----|---------|---------|
| 商业机密 | 未公开的战略、产品、财务信息 | 不得泄露 |
| 个人隐私 | 个人信息、联系方式、身份信息 | 脱敏处理 |
| 监管信息 | 未公开的监管沟通、调查信息 | 严格保密 |
| 法律信息 | 诉讼信息、仲裁信息 | 谨慎处理 |
| 技术信息 | 核心技术、专利、工艺 | 选择性披露 |

#### 7.1.2 脱敏处理建议

**脱敏方法**：

```
脱敏处理清单：

1. 人名脱敏
   原：[具体姓名]
   改：XX公司负责人/涉事员工

2. 金额脱敏
   原：涉及金额XXX万元
   改：涉及金额数百万元/大额

3. 比例脱敏
   原：占比XX%
   改：占比超过X成

4. 日期脱敏
   原：[具体日期]
   改：近日/近期

5. 地点脱敏
   原：[具体地点]
   改：某地/某区域
```

### 7.2 风险预警工具

#### 7.2.1 高风险内容识别

**风险信号**：

```
风险检查项：
□ 是否涉及法律责任的明确表态
□ 是否有未经核实的重要事实
□ 是否可能引发公众误解
□ 是否使用了可能引发争议的措辞
□ 是否泄露了不应公开的信息
□ 是否与之前声明存在矛盾
□ 承诺是否能够兑现
□ 是否可能被断章取义
```

#### 7.2.2 发布风险评估

**风险评估矩阵**：

| 风险等级 | 评估标准 | 处理建议 |
|---------|---------|---------|
| 高风险 | 存在明显法律或声誉风险 | 必须修改或法务审核 |
| 中风险 | 可能存在潜在风险 | 建议修改或谨慎处理 |
| 低风险 | 基本无风险 | 可按流程发布 |
