# 公关稿件撰写专家系统使用指南

## 一、系统简介

### 1.1 系统概述

公关稿件撰写专家系统是专为企业和组织打造的专业公关内容创作工具，旨在帮助公关从业者、品牌管理者、企业高管等快速、高质量地完成各类公关稿件的撰写工作。

本系统凝聚了公关传播领域的专业知识和最佳实践，通过标准化的工作流程、智能化的工具支持和丰富的案例模板，帮助用户提升公关内容创作的质量和效率。

### 1.2 核心价值

**专业保障**：系统融入了公关传播领域的专业理论、写作规范和行业最佳实践，确保输出的内容符合专业标准。

**效率提升**：通过标准化的工作流程和丰富的工具支持，大幅缩短公关稿件的创作时间，提升团队工作效率。

**质量一致**：统一的写作规范和质量检查清单，帮助团队产出风格一致、质量稳定的公关内容。

**风险防控**：内置合规性检查和风险预警功能，帮助用户识别和规避公关传播中的法律和声誉风险。

### 1.3 适用对象

- 企业公关部门
- 品牌管理与市场营销团队
- 企业高管与发言人
- 初创企业创始人
- 政府关系与公共事务部门
- 公关代理公司与咨询机构

## 三、快速开始

### 3.1 基本使用流程

**第一步：了解任务类型**

根据您的公关需求，确定需要使用的工作流程：

| 需求类型 | 推荐工作流 |
|---------|-----------|
| 应对负面事件和舆论危机 | WF-001 危机公关稿件工作流 |
| 发布产品或重要新闻 | WF-002 媒体通稿工作流 |
| 撰写领导人发言内容 | WF-003 高管致辞工作流 |
| 发表官方立场或说明 | WF-004 企业声明工作流 |
| 优化已有的稿件 | WF-005 稿件优化工作流 |

**第二步：准备基础信息**

根据选定的工作流程，准备相关信息：

```
基本信息清单：
□ 企业/组织名称
□ 事件/活动/主题详情
□ 目标受众
□ 发布渠道
□ 时间要求
□ 审批流程
□ 参考素材（如有）
```

**第三步：按照工作流程执行**

按照选定工作流程的步骤，依次完成：

1. 信息收集与需求分析
2. 内容策划与策略制定
3. 初稿撰写
4. 质量审核
5. 优化完善
6. 交付输出

**第四步：使用工具支持**

根据需要使用系统提供的工具：

- 使用创作工具生成初稿和参考内容
- 使用审核工具检查内容质量
- 使用优化工具提升稿件水平
- 使用模板库快速创建标准文档
- 使用案例库参考优秀实践

**第五步：交付发布**

完成最终稿件后，按照企业内部流程进行审批和发布。

### 3.2 场景化使用指南

#### 场景一：危机公关（紧急情况）

**情况描述**：企业突然遭遇负面事件，需要在最短时间内发出危机声明。

**推荐流程**：WF-001 危机公关稿件工作流

**操作步骤**：

1. 打开 `AGENTS.md`，找到"WF-001：危机公关稿件工作流"
2. 根据紧急程度确定响应级别（P0-P3）
3. 按照工作流步骤，快速完成：
   - 信息收集（10分钟）
   - 公关立场确定（15分钟）
   - 稿件结构设计（20分钟）
   - 初稿撰写（30分钟）
   - 合规审查（10分钟）
   - 多版本准备（15分钟）
4. 使用 `TOOLS.md` 中的危机声明模板和词汇库
5. 参考 `docs/examples/example-001-crisis-statement.md` 案例
6. 完成审批后发布

**时间参考**：完整流程约需 2-3 小时

#### 场景二：产品新闻发布（标准流程）

**情况描述**：企业即将发布新产品，需要准备完整的媒体资料包。

**推荐流程**：WF-002 媒体通稿工作流

**操作步骤**：

1. 打开 `AGENTS.md`，找到"WF-002：媒体通稿工作流"
2. 按照工作流步骤完成：
   - 新闻价值评估（10分钟）
   - 核心信息提炼（15分钟）
   - 角度选择（10分钟）
   - 稿件结构设计（15分钟）
   - 初稿撰写（40分钟）
   - 多媒体素材建议（10分钟）
   - 发布渠道规划（10分钟）
3. 使用 `TOOLS.md` 中的标题生成器、导语生成器等工具
4. 参考 `docs/examples/example-002-media-release.md` 案例
5. 使用 `docs/templates/template-media-release.md` 模板
6. 准备完整的媒体资料包

**时间参考**：完整流程约需 4-8 小时

#### 场景三：高管致辞撰写（深度创作）

**情况描述**：CEO 需要在公司周年庆典上发表致辞。

**推荐流程**：WF-003 高管致辞工作流

**操作步骤**：

1. 打开 `AGENTS.md`，找到"WF-003：高管致辞工作流"
2. 分析场合和听众特征
3. 与高管沟通确定个人风格
4. 按照工作流完成：
   - 场景分析（15分钟）
   - 高管风格把握（15分钟）
   - 核心信息设计（20分钟）
   - 致辞结构设计（20分钟）
   - 初稿撰写（60分钟）
   - 口语化调校（20分钟）
   - 配套材料准备（15分钟）
5. 参考 `docs/examples/example-003-executive-message.md` 案例
6. 进行现场演练和调整

**时间参考**：完整流程约需 3-5 天（含沟通和修改）

#### 场景四：稿件优化（质量提升）

**情况描述**：已有初稿需要优化提升，或需要适配不同渠道发布。

**推荐流程**：WF-005 稿件优化工作流

**操作步骤**：

1. 打开 `AGENTS.md`，找到"WF-005：稿件优化工作流"
2. 对原稿进行诊断分析
3. 确定优化类型和优先级
4. 按照工作流完成：
   - 原稿诊断（20分钟）
   - 优化需求确认（10分钟）
   - 优化方案制定（15分钟）
   - 具体优化执行（40-80分钟）
   - 优化对比展示（10分钟）
   - 多版本输出（如需要）
5. 使用 `TOOLS.md` 中的审核工具和质量评分
6. 交付优化稿和优化说明

**时间参考**：完整流程约需 2-4 小时

## 四、工作流详解

### 4.1 五大工作流概览

本系统提供五个专业工作流，覆盖公关稿件撰写的主要场景：

| 工作流 | 编号 | 适用场景 | 紧急程度 |
|-------|-----|---------|---------|
| 危机公关稿件 | WF-001 | 应对负面事件、舆论危机 | 紧急 |
| 媒体通稿 | WF-002 | 产品发布、企业动态 | 标准 |
| 高管致辞 | WF-003 | 重大活动致辞、公开信 | 深度 |
| 企业声明 | WF-004 | 官方立场、情况说明 | 正式 |
| 稿件优化 | WF-005 | 现有稿件诊断与优化 | 优化 |

详细的工作流程规范请参考 `AGENTS.md` 文件。

### 4.2 工作流选择决策树

```
您的需求是？
│
├─ 危机/紧急情况
│   └─ 选择 WF-001 危机公关稿件工作流
│
├─ 新闻发布/企业动态
│   └─ 选择 WF-002 媒体通稿工作流
│
├─ 高管发言/致辞
│   └─ 选择 WF-003 高管致辞工作流
│
├─ 官方声明/立场说明
│   └─ 选择 WF-004 企业声明工作流
│
└─ 优化/改写/适配
    └─ 选择 WF-005 稿件优化工作流
```

### 4.3 工作流组合使用

在复杂的公关场景中，可能需要组合使用多个工作流：

| 场景 | 组合方案 |
|-----|---------|
| 危机 + 高管发声 | WF-001 + WF-003 |
| 产品发布 + 媒体报道 | WF-002 + WF-005 |
| 声明被质疑 | WF-004 + WF-005 |
| 全面危机应对 | WF-001 + WF-002 + WF-004 |

## 五、质量标准

### 5.1 五维质量评估体系

每篇公关稿件都应满足以下五个维度的质量标准：

| 维度 | 权重 | 说明 |
|-----|------|------|
| 准确性 | 25% | 事实核实准确、数据来源可靠、表述清晰无歧义 |
| 得体性 | 25% | 语气恰当、分寸合适、符合企业形象 |
| 时效性 | 20% | 响应及时、发布准时、符合传播节奏 |
| 传播性 | 15% | 可读性强、关注度高、传播潜力大 |
| 合规性 | 15% | 法律合规、监管合规、道德合规 |

### 5.2 质量检查清单

在提交任何稿件之前，请完成以下检查：

**准确性检查**：
- [ ] 所有事实经过核实
- [ ] 所有数据有可靠来源
- [ ] 所有引用与原话一致
- [ ] 表述准确无歧义
- [ ] 逻辑前后一致

**得体性检查**：
- [ ] 语气符合场合要求
- [ ] 分寸把握恰当
- [ ] 符合企业品牌调性
- [ ] 适合目标受众

**时效性检查**：
- [ ] 发布时机合适
- [ ] 内容时效性恰当
- [ ] 响应及时

**传播性检查**：
- [ ] 标题有吸引力
- [ ] 结构清晰易读
- [ ] 核心信息突出
- [ ] 适合目标渠道

**合规性检查**：
- [ ] 经过法务审核
- [ ] 符合监管要求
- [ ] 无敏感信息泄露
- [ ] 无侵权风险

## 七、安全与合规

### 7.1 信息安全提示

**敏感信息处理**：
- 避免在稿件中泄露商业机密
- 个人隐私信息需脱敏处理
- 监管和诉讼信息严格保密
- 未经公开的信息不得披露

**脱敏处理规范**：
- 人名：使用"XX公司负责人"等替代
- 金额：使用"数百万元"等模糊表述
- 日期：使用"近日/近期"等表述
- 地点：使用"某地"等替代

### 7.2 合规发布要求

**发布前必查**：
- [ ] 法务部门审核通过
- [ ] 相关部门负责人确认
- [ ] 高管授权（如需要）
- [ ] 备份存档完成
- [ ] 发布渠道就绪

## 八、常见问题

### 8.1 使用问题

**Q：如何确定应该使用哪个工作流？**
A：请参考本文档"四、工作流详解"部分的选择决策树，或直接描述您的需求，系统将推荐最适合的工作流。

**Q：模板可以直接使用吗？**
A：模板是起点，需要根据具体情况进行调整和定制。请勿直接套用而不做任何修改。

**Q：案例可以照搬吗？**
A：不可以。每个案例都是针对特定情境设计的，需要学习其思路和方法，而非照搬内容。

### 8.2 内容问题

**Q：生成的内容有错误怎么办？**
A：系统生成的内容仅供参考，必须经过人工审核和核实。特别是事实、数据、引用等信息，必须逐一验证。

**Q：如何提升内容的原创性？**
A：系统提供的是框架和参考，真正的原创性来自您对业务和受众的深入理解。请在系统生成的基础上加入您的独特见解和个性化表达。

**Q：内容不符合预期怎么办？**
A：请提供更详细的需求信息，或使用"稿件优化工作流"对不满意的内容进行针对性优化。
