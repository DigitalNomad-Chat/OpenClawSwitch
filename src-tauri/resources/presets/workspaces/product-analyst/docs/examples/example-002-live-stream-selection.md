# 示例002：直播选品案例 - 美妆专场

> **案例类型**：直播选品策划
>
> **行业领域**：美妆护肤
>
> **选品目标**：策划美妆专场直播，提升GMV
>
> **分析周期**：2024年3月

---

## 1. 项目背景

### 1.1 业务背景

某抖音美妆主播，粉丝15万，场均GMV8万元，场均观看1.5万人，转化率5%。主播希望策划一场美妆专场直播，提升GMV到15万元以上。

### 1.2 直播需求

- **直播主题**：春季护肤专场
- **直播时间**：3月15日 20:00-23:00
- **直播时长**：3小时
- **目标GMV**：15万元
- **目标观看**：2万人

### 1.3 主播定位

- **粉丝画像**：20-30岁女性，关注美妆护肤
- **消费能力**：中等消费水平
- **购买偏好**：性价比高、口碑好、有优惠
- **信任度**：主播信任度较高，复购率25%

---

## 2. 主题策划

### 2.1 主题定位

#### 2.1.1 主题确定
**主题**：春季护肤专场 - 唤醒肌肤，迎接春天

**主题解读**：
- 春季是肌肤换季敏感期
- 需要更换适合春季的护肤品
- 强调补水、保湿、修护

#### 2.1.2 目标用户
- **年龄**：20-30岁女性
- **肤质**：混合肌、干肌敏感肌为主
- **需求**：春季护肤、补水保湿、修护敏感
- **消费**：单件50-200元，全场300-500元

#### 2.1.3 直播流程
**20:00-20:30**：开场热身 + 引流款
**20:30-21:30**：核心产品 + 利润款
**21:30-22:30**：组合产品 + 套装款
**22:30-23:00**：清仓秒杀 + 收官

### 2.2 产品组合

#### 2.2.1 产品结构
- **引流款**（10%）：低价爆款，吸引流量
- **利润款**（60%）：主要利润来源
- **形象款**（20%）：提升直播间档次
- **清货款**（10%）：清理库存

#### 2.2.2 品类分布
- **护肤品类**（50%）：面膜、水乳、面霜、精华
- **彩妆品类**（30%）：口红、粉底、眼影
- **工具品类**（20%）：化妆刷、美妆蛋、洁面仪

## 4. 价格策略

### 4.1 定价原则

#### 4.1.1 原则
- **确保利润**：毛利率≥25%
- **价格优势**：低于市场价10-30%
- **价格吸引力**：明显的价格优势
- **价格合理性**：不影响品质认知

#### 4.1.2 价格体系

**引流款定价**：
- 补水面膜：市场价99元，直播价39元（4折）
- 定位：超低价引流，不追求利润

**利润款定价**：
- 精华液：市场价299元，直播价159元（5.3折）
- 水乳套装：市场价399元，直播价199元（5折）
- 面霜：市场价259元，直播价129元（5折）
- 定位：主要利润来源，确保毛利率

**形象款定价**：
- 维C精华：市场价599元，直播价399元（6.7折）
- 鱼子酱面霜：市场价899元，直播价599元（6.7折）
- 定位：提升档次，适当利润

**清货款定价**：
- 口红：市场价199元，直播价69元（3.5折）
- 定位：清理库存，回笼资金

### 4.2 促销策略

#### 4.2.1 限时秒杀
- **时间**：20:00-20:30
- **产品**：补水面膜
- **价格**：39元（限量500份）

#### 4.2.2 专属优惠
- **时间**：全场
- **优惠**：直播间专属价格
- **力度**：低于市场价10-30%
- **策略**：强调专属感，提升转化

#### 4.2.3 套餐优惠
- **套餐1**：水乳套装 + 面膜 = 229元（省28元）

#### 6.1.2 核心产品（20:30-22:30）
- **产品介绍**：详细讲解产品卖点
- **现场演示**：现场试用展示效果
- **用户见证**：展示用户评价
- **限时优惠**：强调限时优惠

#### 6.2.1 实时监控

- **销售数据**：实时销量和销售额
