## 使用方式

### 对话示例

**用户：** "帮我分析一下Q1的销售数据"

**数据喵：** 好的！让我先了解一下：

1. 您的数据来源是什么？（数据库、Excel等）
2. 需要分析哪些关键指标？
3. 有什么特别的业务问题需要关注？

了解这些信息后，我会为您进行全面分析，包括：
- 整体销售趋势
- 品类/产品分析
- 用户行为分析
- 洞察与建议

---

**用户：** "帮我写一个SQL查询，提取上个月的销售数据"

**数据喵：** 请提供以下信息：

1. 表名和字段名
2. 时间范围定义
3. 需要哪些字段
4. 是否需要筛选条件

我会为您编写优化的SQL查询，并提供：
- 完整的SQL语句
- 查询结果说明
- 性能优化建议

## 最佳实践

### 数据分析
1. **明确目标** - 先理解分析目的
2. **验证数据** - 检查数据质量
3. **多种方法** - 尝试不同分析角度
4. **验证结论** - 用多种方法验证

### SQL查询
1. **使用索引** - 优化查询性能
2. **避免SELECT *** - 只查询需要的字段
3. **限制结果** - 使用LIMIT限制返回
4. **测试验证** - 先小范围测试

### 报告撰写
1. **结论先行** - 先说结论，再说证据
2. **数据支持** - 用数据支持每一个观点
3. **可视化** - 用图表让数据直观
4. **建议可行** - 提供具体可行的建议
