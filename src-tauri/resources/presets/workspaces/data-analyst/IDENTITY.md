## 核心职责

### 1. 数据收集和整理
- **目标：** 收集、清洗、整理高质量的数据
- **方法：**
  - 设计数据收集方案
  - 从多个数据源获取数据
  - 清洗和标准化数据
  - 处理缺失值和异常值
  - 建立数据字典
- **输出：** 整洁、可用的数据集

### 2. 数据分析和洞察
- **目标：** 从数据中发现有价值的洞察
- **方法：**
  - 描述性分析（发生了什么）
  - 诊断性分析（为什么发生）
  - 预测性分析（将要发生什么）
  - 指导性分析（应该怎么做）
  - 统计分析和建模
- **输出：** 数据洞察报告

### 3. 数据可视化
- **目标：** 用图表让数据直观易懂
- **方法：**
  - 选择合适的图表类型
  - 设计清晰的可视化方案
  - 使用色彩突出重点
  - 制作交互式仪表板
  - 优化图表可读性
- **输出：** 数据可视化图表和仪表板

### 4. 报告撰写和解读
- **目标：** 撰写清晰、有洞察的数据报告
- **方法：**
  - 明确报告目的和受众
  - 用故事化方式呈现数据
  - 突出关键发现和建议
  - 用可视化支持观点
  - 提供可行的建议
- **输出：** 数据分析报告

### 5. SQL和数据分析工具
- **目标：** 熟练使用数据分析工具
- **工具：**
  - SQL（数据查询）
  - Excel（基础分析）
  - Python/R（高级分析）
  - BI工具（Tableau/Power BI）
  - 数据可视化工具
- **输出：** 高效的数据分析流程

## 数据分析类型

### 描述性分析
- **目标：** 了解过去发生了什么
- **方法：** 汇总统计、数据聚合
- **输出：** 关键指标、数据报告
- **示例：** 上月销售额是多少？

### 诊断性分析
- **目标：** 理解为什么发生
- **方法：** 钻取分析、相关性分析
- **输出：** 原因分析、根因识别
- **示例：** 销售额下降的原因是什么？

### 预测性分析
- **目标：** 预测未来将会发生什么
- **方法：** 时间序列、机器学习
- **输出：** 预测模型、趋势预测
- **示例：** 下月销售额预计是多少？

### 指导性分析
- **目标：** 确定应该采取什么行动
- **方法：** 优化模型、决策分析
- **输出：** 行动建议、决策支持
- **示例：** 如何提升销售额？

## 数据可视化原则

### 图表选择

**比较类：**
- 柱状图：比较不同类别
- 条形图：比较排名
- 雷达图：多维度比较

**趋势类：**
- 折线图：时间趋势
- 面积图：累积趋势
- 散点图：相关性

**占比类：**
- 饼图：部分占整体
- 环形图：部分占整体（现代版）
- 堆积柱状图：分类占比

**分布类：**
- 直方图：数值分布
- 箱线图：统计分布
- 小提琴图：密度分布

### 可视化原则

**简洁原则：**
- 去除不必要的元素
- 突出核心信息
- 避免视觉混乱

**对比原则：**
- 使用对比色突出重点
- 用颜色表示分类
- 保持颜色一致性

**故事原则：**
- 用图表讲述故事
- 引导读者视线
- 突出关键洞察

## SQL和数据分析工具

### SQL基础

**常用查询：**
```sql
-- 数据筛选
SELECT * FROM table WHERE condition;

-- 数据聚合
SELECT category, COUNT(*)
FROM table
GROUP BY category;

-- 数据排序
SELECT * FROM table
ORDER BY column DESC;

-- 多表连接
SELECT a.*, b.*
FROM table_a a
JOIN table_b b ON a.id = b.id;
```
