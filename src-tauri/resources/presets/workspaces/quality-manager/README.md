## 术语表

为了帮助您更好地理解质量管理专业术语，以下提供常用术语的简要说明：

ISO 9001是国际标准化组织发布的质量管理体系标准，是全球应用最广泛的质量管理认证标准。

PDCA循环是质量管理的基本方法论，包括计划（Plan）、执行（Do）、检查（Check）、行动（Act）四个阶段，通过循环往复实现持续改进。

SPC是统计过程控制的缩写，是一种通过统计方法监控和控制生产过程质量的技术手段。

FMEA是潜在失效模式与影响分析的缩写，是一种预防性的风险分析工具。

DMAIC是六西格玛改进的方法论框架，包括定义（Define）、测量（Measure）、分析（Analyze）、改进（Improve）、控制（Control）五个阶段。

内审是内部审核的简称，是企业自行组织对质量管理体系运行有效性进行评价的活动。

管理评审是最高管理者主持的对质量管理体系适宜性、充分性和有效性的系统评价活动。

不符合项是审核中发现的质量管理体系不符合标准要求的项，需要采取纠正措施。

当您面临复杂的质量管理问题时，可以通过深度问题咨询获得更全面的支持。建议按照以下步骤进行深度咨询：首先，描述您面临的具体问题和背景情况，越详细越好；其次，说明您已经尝试过的解决方法及其效果；第三，说明您希望达到的目标或期望；第四，询问Agent能否提供系统化的解决方案。Agent会针对您的具体问题，提供从分析到实施的完整方案建议。

如果您需要Agent协助完成较复杂的工作项目，可以通过项目化服务申请获得持续性的支持。项目化服务包括以下流程：需求沟通阶段，Agent与您深入交流，明确项目目标、范围、时间和资源要求；方案设计阶段，Agent制定详细的项目方案，包括工作流程、交付物清单、时间计划等；项目实施阶段，Agent按照方案推进项目执行，定期汇报进展并及时处理问题；项目验收阶段，Agent提交项目成果并协助您进行验收确认。

### 定制化服务

如果标准化的服务无法满足您的特殊需求，Agent可以提供定制化服务。定制化服务包括：针对特定行业（如医疗器械、汽车、食品等）的质量管理方案定制；针对特定方法（如六西格玛、精益生产等）的深度培训和辅导；针对特定问题（如供应商质量管理、客户投诉处理等）的专项诊断和改进；针对特定文件（如质量手册、程序文件等）的定制化编制指导。
