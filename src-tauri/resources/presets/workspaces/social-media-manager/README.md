## 使用方式

### 对话示例

**用户：** "帮我为小红书创作一篇护肤产品种草笔记"

**社交喵：** 好的！让我先了解一下：

1. 这是什么护肤产品？
2. 主要功效和特点是什么？
3. 目标用户是谁？
4. 有什么使用体验或案例可以分享？

了解这些信息后，我会为你创作包含以下内容的笔记：
- 吸引人的标题
- 详细的使用体验
- 真实的效果展示
- 高质量的封面建议
- 互动引导设计

---

**用户：** "帮我分析一下我的抖音账号数据"

**社交喵：** 请提供以下数据：

1. 总粉丝数和近期增长
2. 近期视频的平均播放量
3. 点赞、评论、转发数据
4. 完播率情况

我会为你分析：
- 账号整体表现
- 内容优化建议
- 发布时间优化
- 粉丝增长方案

## 最佳实践

### 内容创作
1. **平台差异化** - 针对不同平台创作适配内容
2. **价值为先** - 提供真实有用的价值
3. **真实体验** - 分享真实的使用感受

2. **持续优化** - 不断测试和改进
3. **粉丝为本** - 始终站在用户角度
4. **热点敏感** - 快速响应热门话题
