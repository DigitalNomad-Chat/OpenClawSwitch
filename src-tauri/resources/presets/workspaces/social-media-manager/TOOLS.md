## 平台运营要点

### 小红书运营要点

**内容特点：**
- 图文并茂，重视视觉
- 真实体验分享
- 种草属性强
- 生活方式展示

**运营技巧：**
1. 优化封面和标题
2. 使用热门话题标签
3. 保持真实体验
4. 积极回复评论
5. 保持更新频率

**发布时间：**
- 工作日：12:00-14:00, 18:00-22:00
- 周末：10:00-12:00, 14:00-22:00

- 配合热门BGM
- 参与话题挑战

**运营技巧：**
1. 优化视频开头
2. 使用热门音乐
3. 参与热门挑战
4. 保持更新频率
5. 积极互动回复

**发布时间：**
- 工作日：12:00-14:00, 18:00-24:00
- 周末：10:00-12:00, 14:00-24:00

### 公众号运营要点

**内容特点：**
- 深度图文内容

## 常用内容模板

### 小红书笔记模板

```markdown
标题：{吸引人的标题}

封面：{精美封面图}

正文：
{开头：引发兴趣}

{主体：详细内容}
- 要点1
- 要点2
- 要点3

{结尾：总结和引导}

标签：#标签1 #标签2 #标签3

位置：{地点（可选）}
```

### 抖音视频脚本模板

```markdown
标题：{吸引人的标题}

时长：{15-60秒}

脚本：
[0-3秒] 吸引注意
{钩子内容}

[3-10秒] 主体内容
{核心内容}

[10-15秒] 互动引导
{CTA内容}

BGM：{背景音乐}
特效：{视频特效}
标签：{相关话题}
```

### 公众号文章模板

```markdown
标题：{吸引人的标题}

封面图：{精美封面}

摘要：{文章摘要}

正文：
{开头：引入话题}

{主体：详细内容}
## 小节1
{内容}

## 小节2
{内容}

{结尾：总结和引导}

{引导互动}
{关注引导}

{签名/版权}
```

## 数据指标参考

### 粉丝增长指标

**健康增长：**
- 日增长率：0.5%-1%
- 周增长率：3%-5%
- 月增长率：15%-25%

**异常情况：**
- 负增长：需要检查内容
- 零增长：需要优化策略
- 暴涨：可能是买粉或爆款

### 互动率指标

**优秀水平：**
- 小红书：10%+
- 抖音：5%+
- 公众号：3%+

**一般水平：**
- 小红书：5%-10%
- 抖音：2%-5%
- 公众号：1%-3%

**需优化：**
- 低于以上水平

### 内容质量指标

**优秀内容：**
- 曝光率高于平均水平50%+
- 互动率高于平均水平30%+
- 转化率高于平均水平20%+
