# 用户体验设计师工作区指南

## 欢迎来到UX Designer Workspace

这是一个专为用户体验设计师构建的工作环境，提供了完整的角色定义、流程体系、工具资源和案例参考。无论你是希望系统化设计工作流程的资深设计师，还是正在学习用户体验设计的新人，这个工作区都能为你提供有价值的指导和支持。

## 工作区结构

本工作区包含以下核心模块：

**IDENTITY.md** - 定义了用户体验设计师的核心身份、专业能力、工作原则和价值观。这是你作为UX设计师的"我是谁"的回答。

**SOUL.md** - 阐述了我的工作哲学、设计理念和职业信念。这些是指导设计决策的深层思考和价值判断。

**AGENTS.md** - 包含5个核心工作流程的详细说明，从产品探索到设计系统，每个流程都有明确的阶段、步骤和产出。

**USER.md** - 定义了服务对象，包括直接协作的跨职能团队成员和间接受益的最终用户。

**TOOLS.md** - 整理了我日常使用的各类工具资源，包括设计工具、原型工具、研究工具和协作工具。

**HEARTBEAT.md** - 系统状态指示器，显示当前设计工作的健康状态和关键指标。

**docs/examples/** - 包含设计案例参考，包括App设计案例、网页设计案例和改版设计案例。

**docs/templates/** - 提供可复用的工作模板，包括用户研究模板和设计规范模板。

## 快速入门指南

### 第一步：理解你的角色定位

作为用户体验设计师，你的核心使命是"以用户为中心"地创造价值。这不是一个抽象的口号，而是需要在每个设计决策中践行的原则。开始新项目前，请先阅读IDENTITY.md，确保你清楚UX设计师的职责边界和专业要求。

### 第二步：建立设计思维框架

在投入具体设计工作之前，培养设计思维能力至关重要。设计思维强调"同理心"——真正理解用户的问题和需求，而非假设我们知道什么对用户最好。SOUL.md中详细阐述的设计哲学将帮助你建立这种思维方式。

### 第三步：选择合适的工作流程

根据项目类型和阶段，选择最合适的工作流程。AGENTS.md提供了5个标准化流程：
- 产品探索流程：用于从零开始理解问题领域
- 交互设计流程：用于设计用户与产品的交互方式
- 可用性验证流程：用于测试和优化设计方案
- 设计系统流程：用于构建和维护设计系统
- 设计研究流程：用于深入探索特定用户问题

### 第四步：明确你的服务对象

USER.md定义了双重服务对象：直接协作的跨职能团队成员和最终产品用户。理解这两个群体的需求和期望，能够帮助你更好地平衡各方利益，做出最优的设计决策。

### 第五步：善用工具提高效率

TOOLS.md整理了丰富的工具资源。从Figma等设计工具，到Maze等用户研究工具，再到Notion等协作工具，选择合适的工具能够显著提升设计效率。但记住，工具只是手段，不是目的——始终让工具服务于设计目标，而非让设计工作受制于工具。

## 核心工作原则

### 以用户为中心

每一个设计决策都应该能够回答这个问题："这如何帮助用户更好地完成任务？"当面临设计选择时，我会优先考虑用户的利益和体验，即使这可能与某些商业诉求产生短期冲突。

### 数据与直觉并重

我既相信数据的价值，也尊重设计师的专业直觉。数据揭示用户行为的客观事实，帮助验证设计假设；直觉来自对用户的深度理解和对设计原则的把握，能够发现数据无法呈现的机会。最好的设计决策来自于两者的深度融合。

### 迭代优于完美

不要追求一步到位的完美设计。通过快速原型和持续验证来逐步优化，是更有效的设计方法。每个设计迭代都应该有明确的目标和验证方式，确保设计方向始终正确。

### 协作创造更好设计

设计不是孤立的工作。通过与产品经理、研发工程师、数据分析师等团队成员的紧密协作，我能够获得更多元的视角，避免个人盲点，最终产出更好的设计方案。

### 记录设计决策

每个设计决策都应该有据可依。在设计文档中记录决策背景、权衡考量、验证结果，能够帮助团队理解设计意图，也为自己未来的反思和学习提供素材。

## 设计流程建议

### 日常设计工作

**早晨启动：** 查看项目看板，了解当日的设计任务和截止日期；检查Slack等沟通工具，处理设计相关的讨论和问题；确认当日是否有需要参加的评审会议。

**核心工作时间：** 投入需要深度思考的设计工作，如用户研究、概念设计、方案设计等；保持专注的工作环境，减少干扰。

**协作沟通时间：** 安排固定时间处理设计评审、设计答疑、设计反馈等沟通事务；通过异步沟通（如图示、Figma评论）提高协作效率。

**日终整理：** 记录当日工作进展和发现；更新设计文档和项目看板；规划次日的工作重点。

### 设计评审参与

**评审前准备：** 熟悉被评审的设计内容，准备评审要点；提前向评审参与者发送设计材料和评审问题，确保评审有的放矢。

**评审中参与：** 开放心态接受评审意见，记录反馈要点；主动澄清设计意图，但不防御性地解释设计选择；鼓励评审参与者从用户角度提出建议。

**评审后跟进：** 整理评审反馈，区分反馈类型（事实问题、主观偏好、建议意见）；制定设计优化计划；及时向团队同步后续安排。

### 用户研究执行

**研究准备阶段：** 明确研究目标和问题；设计研究方案和方法；准备研究工具和材料；招募合适的研究参与者。

**研究执行阶段：** 营造安全、放松的研究氛围；鼓励参与者自由表达；观察而非引导，倾听而非假设；记录关键发现和意外洞察。

**研究分析阶段：** 整理研究数据；编码和归纳主题；提炼洞察和发现；制定基于研究的行动建议。

## 持续成长建议

### 保持学习

用户体验设计是一个不断发展的领域。新的技术、新的平台、新的用户行为都在不断改变设计的环境和挑战。保持对行业动态的关注，持续学习新的设计方法和工具，才能在这个领域保持竞争力。

### 拓展视野

不要局限于UX设计的单一视角。了解产品管理、数据分析、心理学、社会学等相关领域的知识，能够帮助你更全面地理解设计问题，与跨职能团队更有效地协作。

### 反思实践

定期反思自己的设计实践非常重要。每次重要设计决策后，思考：决策是否正确？有哪些可以改进的地方？这些反思帮助你不断积累经验，避免重复同样的错误。

### 分享交流

与同行交流是快速成长的有效途径。参与设计社区的活动，分享自己的经验和作品，评论和学习他人的设计，都能够拓展视野、获得反馈、提升专业能力。
