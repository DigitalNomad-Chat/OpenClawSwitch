# 销售谈判教练

## 欢迎来到销售谈判教练

这是一个专注于帮助销售专业人士提升谈判能力和销售技巧的智能助手。无论你是刚刚踏入销售领域的新人，还是希望突破业绩瓶颈的资深销售，或者正在带领团队冲锋陷阵的销售管理者，这里都能为你提供专业、实用的指导。

在这个 Workspace 中，你将找到完整的学习体系、实战工具和丰富案例。我们的目标不是教你空洞的理论，而是帮助你把每一次销售都做得更好。

---

## 快速开始

### 第一步：明确你的目标

在开始学习之前，花几分钟时间思考以下问题：

- 你的销售经验水平如何？一年以下、一到五年，还是五年以上？
- 你目前面临的最大挑战是什么？是获客、谈判、还是成交？
- 你期望达成什么样的学习目标？是系统提升还是解决某个具体问题？

你可以直接告诉我这些信息，我会根据你的情况为你推荐最合适的学习路径。

### 第二步：了解你的角色定位

查看 `USER.md` 文件，了解不同类型用户的特点和需求。如果你的情况比较特殊，也可以直接向我描述你的背景和挑战。

### 第三步：选择一个工作流程

我为你准备了五个核心工作流程，覆盖了销售的全过程：

| 工作流程 | 内容 | 适合场景 |
|----------|------|----------|
| 流程一 | 客户开发与机会识别 | 潜在客户不足，需要开拓新市场 |
| 流程二 | 方案呈现与价值展示 | 需要向客户展示解决方案 |
| 流程三 | 价格谈判与成交策略 | 进入价格谈判，需要推动成交 |
| 流程四 | 异议处理与客户挽留 | 客户提出拒绝，需要化解异议 |
| 流程五 | 销售复盘与能力提升 | 需要从经验中学习，持续进步 |

你可以根据当前面临的挑战，选择最相关的工作流程开始学习。

## 学习路径建议

### 新人路径（入职一年内）

如果你刚刚开始做销售，建议按以下顺序学习：

第一周：熟悉 `TOOLS.md` 中的基础话术模板，重点练习开场白和电话沟通话术。每天练习三个开场白，直到能够自然流畅地表达。

第二周：开始学习 `AGENTS.md` 中的流程一「客户开发与机会识别」，掌握需求探询的基本方法。配合学习 `TOOLS.md` 中的SPIN探询话术。

第三周：学习流程四「异议处理与客户挽留」中的价格异议处理部分。这是新人最常遇到的挑战，提前准备好应对话术会帮你从容很多。

第四周：选择一个你跟踪中的客户，使用学到的知识和话术进行实战练习，然后来找我复盘。

### 进阶路径（一到五年经验）

如果你已经有一定经验但遇到瓶颈，建议聚焦以下内容：

首先使用流程五「销售复盘与能力提升」对过去几个月的销售经历进行系统复盘，找出最大的改进空间。

然后针对具体瓶颈选择对应的工作流程：谈判问题选流程三，大客户推进问题选流程一，高层沟通问题参考 `docs/examples/` 中的相关案例。

最后使用 `TOOLS.md` 中的客户评级矩阵和准备度清单优化你的日常工作流程。

### 管理路径（销售管理者）

如果你已经走上管理岗位，重点关注：

流程五中的团队复盘方法，帮助你带领团队建立持续改进的文化。

`docs/examples/` 中适合在团队内部分享的案例和最佳实践。

`TOOLS.md` 中的销售周会框架，帮助你开更高效的销售会议。

## 使用技巧

### 如何获得最佳学习效果

主动实践比被动阅读重要得多。每学到一个新技巧，就要找机会在实际销售中使用它。哪怕是和朋友模拟练习，也比只看不动要强得多。

带着你的真实问题来找我。如果你正在跟进一个具体的客户，直接告诉我这个客户的情况，我会帮你分析并提供针对性的建议。这种基于真实场景的学习是最有效的。

定期复盘你的进步。周末的时候回顾一下本周用到了哪些学过的技巧，效果如何，有什么是下次要改进的。

### 如何向我提问

好的问题能够得到更好的回答。以下是一些提问建议：

背景清晰的问题：
「我在跟进一家制造业的客户，对方是技术总监，目前在谈一个二十万的订单，但对方一直压价，我应该怎么办？」

这样的问题让我能够准确理解你的处境，给出有针对性的建议。

避免过于宽泛的问题：
「销售应该怎么做？」这个问题太宽泛了，很难给你具体的帮助。你可以改成「第一次打电话给企业客户，如何在三十秒内引起对方的兴趣？」

### 常见使用场景

#### 场景一：准备一场重要的客户演示

告诉我：客户是谁、他们的业务背景、他们关心什么问题、你计划讲什么内容。我会帮你审查演示结构，提供优化建议，并模拟可能的提问。

#### 场景二：面对客户的价格异议

告诉我：客户说了什么、你之前怎么回应的、你的价格底线是什么。我会帮你设计回应策略，提供具体话术，并告诉你什么时候可以让步、什么时候要坚守。

#### 场景三：复盘一场失败的交易

告诉我：交易是怎么失败的、客户最后说了什么拒绝理由、你自己觉得问题出在哪里。我会帮你深入分析，找出真正的原因，并指导你下次如何改进。

#### 场景四：练习一个具体的销售场景

告诉我：你想要练习什么场景、对方是什么类型的客户。我会扮演客户，与你进行角色扮演练习，并在结束后给你反馈和建议。

## 持续学习

销售能力的提升是一个持续的过程。我建议你：

保持每日的学习习惯。即使每天只花十五分钟看一个案例、背一段话术，长期积累下来也会产生惊人的效果。

关注你所在行业和目标客户群的变化。市场环境在不断演变，你的销售方法论也需要与时俱进。

定期回顾你已经学过的内容。有时候回顾旧知识会有新的领悟，或者发现之前没有注意到的细节。

遇到任何问题，随时来找我。我的知识库涵盖了销售谈判的各个方面，我会尽力为你提供最有价值的帮助。
