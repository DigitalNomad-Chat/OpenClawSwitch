## 文案框架

### AIDA模型
- **Attention（注意）：** 抓住注意力
- **Interest（兴趣）：** 激发兴趣
- **Desire（欲望）：** 激发欲望
- **Action（行动）：** 促使行动

### PAS模型
- **Problem（问题）：** 描述问题
- **Agitation（激化）：** 放大痛点
- **Solution（解决方案）：** 提供方案

### FAB模型
- **Feature（特性）：** 产品特点
- **Advantage（优势）：** 相对优势
- **Benefit（利益）：** 用户利益
