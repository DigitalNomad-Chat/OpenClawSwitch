## 推荐工具

### 文案创作工具

**标题生成器**
- 用途：快速生成吸引人的标题选项
- 推荐：
  - CoSchedule Headline Analyzer
  - Advanced Marketing Institute Headline Tool
  - AMI Headline Analyzer

**情感词库**
- 用途：选择有情感色彩的词汇
- 推荐：
  - Power Thesaurus
  - Emotional Vocabulary Word List
  - AWeber's List of Power Words

**文案分析工具**
- 用途：分析文案质量和可读性
- 推荐：
  - Hemingway Editor（可读性分析）
  - Grammarly（语法检查）
  - Readable.com（综合分析）

### A/B测试工具

**邮件测试**
- 用途：测试邮件主题和内容
- 推荐：
  - Mailchimp A/B Testing
  - Campaign Monitor
  - ConvertKit

**落地页测试**
- 用途：测试页面文案效果
- 推荐：
  - Google Optimize
  - Optimizely
  - VWO

**广告测试**
- 用途：测试广告文案
- 推荐：
  - Facebook Ads Manager
  - Google Ads
  - LinkedIn Campaign Manager

### 数据分析工具

**网站分析**
- 用途：追踪文案转化效果
- 推荐：
  - Google Analytics
  - Hotjar（用户行为）
  - Mixpanel

**社交媒体分析**
- 用途：分析社媒文案表现
- 推荐：
  - 各平台原生分析工具
  - Sprout Social
  - Hootsuite Analytics

## 文案框架和模型

### 经典框架

**AIDA模型**
- Attention（注意）
- Interest（兴趣）
- Desire（欲望）
- Action（行动）

**PAS模型**
- Problem（问题）
- Agitation（激化）
- Solution（解决方案）

**FAB模型**
- Feature（特性）
- Advantage（优势）
- Benefit（利益）

**4U模型**
- Urgent（紧迫）
- Unique（独特）
- Useful（有用）
- Ultra-specific（具体）

### 现代框架

**BAB模型**
- Before（之前）
- After（之后）
- Bridge（桥梁）

**STAR模型**
- Situation（情境）
- Task（任务）
- Action（行动）
- Result（结果）

** QUEST模型**
- Qualify（筛选）
- Understand（理解）
- Educate（教育）
- Stimulate（刺激）
- Transition（过渡）

## 文案检查清单

### 发布前检查

**基础检查**
- [ ] 拼写和语法正确
- [ ] 标题吸引人
- [ ] 开头有钩子
- [ ] 价值主张清晰
- [ ] CTA明确

**质量检查**
- [ ] 文案流畅
- [ ] 逻辑清晰
- [ ] 语言简洁
- [ ] 有说服力
- [ ] 符合品牌调性

**效果检查**
- [ ] 目标明确
- [ ] 受众匹配
- [ ] 平台适配
- [ ] SEO优化（如需要）
- [ ] 移动端友好

### A/B测试检查

**测试准备**
- [ ] 明确测试目标
- [ ] 定义测试变量
- [ ] 确定样本大小
- [ ] 设置测试周期

**数据分析**
- [ ] 收集足够数据
- [ ] 分析统计显著性
- [ ] 记录洞察
- [ ] 制定行动计划

## 常用提示词模板

### 商品详情页文案
```
请为以下产品创作商品详情页文案：
产品名称：{产品名}
核心特点：{特点列表}
目标用户：{用户描述}
主要痛点：{痛点列表}

请使用AIDA模型，包含：
1. 吸引注意的标题
2. 痛点描述
3. 产品介绍
4. 社会证明
5. 明确的CTA
6. 风险逆转元素
```

### 广告文案
```
请为以下产品/服务创作广告文案：
产品/服务：{描述}
目标受众：{受众描述}
核心利益：{利益点}
广告平台：{平台}

要求：
- 简洁有力（100字以内）
- 强烈的钩子
- 清晰的价值主张
- 明确的CTA
- 紧迫感元素

请提供3个版本供选择。
```

### 营销邮件
```
请创作一封营销邮件：
邮件目标：{目标}
目标受众：{受众}
核心内容：{内容}
CTA：{行动号召}

请包含：
1. 3个主题行选项
2. 个性化开场
3. 价值内容
4. 明确的CTA
5. P.S.强化

注意：邮件应简洁、友好、有价值。
```

### 社交媒体文案
```
请为以下内容创作社交媒体文案：
平台：{平台}
内容主题：{主题}
核心信息：{信息}

要求：
- 吸引注意的开头
- 有价值的内容
- 互动引导
- 相关话题标签
- 适合平台特点
```
