# USER.md - 目标用户定义

## 核心用户画像

### 1. 科普自媒体创作者
- **用户特征**：自媒体账号运营者、知识类博主
- **主要内容平台**：微信公众号、知乎、B站、抖音、小红书
- **核心需求**：持续产出高质量科普内容、建立专业形象、获取流量和粉丝
- **内容需求**：科技科普、健康科普、财商教育、人文历史
- **典型痛点**：专业知识不足、创作效率低、内容质量不稳定、难以持续更新

### 2. 教育机构内容团队
- **用户特征**：在线教育平台、培训机构、学校内容部门
- **主要内容平台**：自有平台、公众号、视频平台
- **核心需求**：系统化科普内容、教育性内容、知识库建设
- **内容需求**：学科科普、学习方法、技能培养、知识拓展
- **典型痛点**：内容体系不完整、更新不及时、专业性不足、学生参与度低

### 3. 企业内容部门
- **用户特征**：企业市场部、品牌部、产品部
- **主要内容平台**：企业官网、公众号、行业媒体
- **核心需求**：行业知识科普、产品教育、品牌建设、用户教育
- **内容需求**：行业趋势、产品知识、技术应用、解决方案
- **典型痛点**：内容过于专业、用户难以理解、缺乏吸引力、转化率低

### 4. 知识付费创作者
- **用户特征**：知识博主、课程创作者、专栏作家
- **主要内容平台**：得到、知乎盐选、小鹅通、知识星球
- **核心需求**：深度知识内容、体系化课程、付费内容价值
- **内容需求**：专业知识、实用技能、认知提升、问题解决
- **典型痛点**：内容深度不足、实用性不够、缺乏体系、用户复购率低

## 使用场景

### 场景1：日常科普内容创作
- **使用频率**：高频（每天或每周）
- **内容形式**：科普文章、短视频、图文
- **创作周期**：1-3天
- **主要需求**：快速产出、保持质量、持续更新
- **典型流程**：选题→创作→发布→互动

### 场景2：热点事件科普解读
- **使用频率**：中频（根据热点）
- **内容形式**：热点解读文章、短视频
- **创作周期**：几小时到1天
- **主要需求**：快速响应、准确解读、时效性强
- **典型流程**：热点捕捉→快速研究→内容创作→及时发布

### 场景3：系列科普内容规划
- **使用频率**：低频（季度或年度）
- **内容形式**：系列文章、系列视频、课程
- **创作周期**：几周到几个月
- **主要需求**：系统规划、批量创作、形成体系
- **典型流程**：主题规划→内容设计→批量创作→系列运营

### 场景4：知识营销内容创作
- **使用频率**：中频（月度或季度）
- **内容形式**：产品科普、行业白皮书、解决方案
- **创作周期**：1-2周
- **主要需求**：专业权威、营销转化、品牌建设
- **典型流程**：需求分析→内容策划→创作优化→发布转化

### 场景5：科普内容优化升级
- **使用频率**：低频（半年度或年度）
- **内容形式**：内容库优化、质量提升
- **创作周期**：持续进行
- **主要需求**：数据驱动、问题诊断、持续优化
- **典型流程**：数据复盘→问题诊断→优化方案→内容改进
